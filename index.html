Project Yang Pernah Dibuat

Berikut adalah template showcase project yang telah diselesaikan. Anda dapat dengan mudah menyesuaikan detail project ini di masa mendatang.

Laravel 12 MySQL FIFO Stock DDMS Bengkel Dashboard Owner

Sistem Dealer & Bengkel Honda (DDMS)

Aplikasi manajemen bengkel komprehensif yang dirancang untuk mengelola siklus keluar-masuk barang, mulai dari Purchase Order (PO) hingga Receive Order (RO). Mengelola data master lengkap (Customer, Supplier, Karyawan, Mekanik), input penjualan, data motor customer, serta modul pengelolaan stok dengan algoritma FIFO. Memiliki antarmuka yang setara dengan web resmi DDMS Honda, dilengkapi dashboard visual untuk owner bengkel.

Laravel 13 ERP System FIFO Inventory Inbound & Outbound MySQL Dashboard Owner

ERP PT Hayami Kreasi Indonesia

Sistem ERP terpadu berbasis Laravel 13 dan MySQL untuk meningkatkan efisiensi rantai pasok perusahaan. Mengatur siklus inbound barang masuk (Purchase Order dan Receive Order), pemindahan lokasi barang setelah penerimaan (RO), serta pengelolaan outbound barang keluar untuk pesanan penjualan. Dilengkapi dengan kontrol stok berbasis metode FIFO yang presisi, pengelolaan master data (karyawan, customer, supplier, inventori barang), serta dashboard analitik interaktif khusus bagi owner untuk monitoring perkembangan bisnis.
